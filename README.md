# Projeto de Infraestrutura - WaterSoft Limitada
## Resumo
Planejamento de infraestrutura para uma empresa fictícia de consultoria com 4 andares de um prédio, um total de 70 funcionários. A solução reúne computadores, servidores, sistemas, redes e IoT.
## Organização
* `01-Empresa/`: empresa, organograma e postos.
* `02-Arquitetura/`: computadores, servidor, RAID, energia e orçamento.
* `03-Sistemas-Operacionais/`: sistemas, serviços, permissões, backup e licenças.
* `04-Redes/`: plantas, topologia, VLANs, IPv4, Wi-Fi e equipamentos.
* `05-IoT/`: código, circuito e três testes.
* `07-Referencias/`: referências usadas durante o projeto.

Evidências que seria o 06 dentro das outras pastas.

## Como consultar
Comece por `01-Empresa` e siga as pastas `02` a `07`. Em cada uma, abra a planilha ou explicação principal indicada.
